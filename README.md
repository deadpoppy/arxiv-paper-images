# Arxiv Paper Images

This repository stores images from arxiv papers for faster access in China.

## Usage

Use the jsDelivr CDN for accelerated access:

```
https://cdn.jsdelivr.net/gh/deadpoppy/arxiv-paper-images@main/images/FILENAME
```

## Images

All images are stored in the `images/` directory with filenames derived from their original arxiv URLs.
